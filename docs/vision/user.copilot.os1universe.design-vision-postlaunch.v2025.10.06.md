# Post-Launch Normality
## Phone → Intent Layer
- No app hunt; typed/voiced intents route across services.
- Silent = semantic mode.

## Desktop → Workbench
- Word/IDE/Browser/Files/Canvas converge into one neural canvas.
- Manuals replaced by self-explaining interactions.

## Onboarding Modes
- A) Treasure Hunt → auto profile (+ horoscope).
- B) Two Strangers Conversation (preferred).
- C) Epic Saga Gateway.

## Principles
- Using = Knowing; the system teaches itself while serving.
