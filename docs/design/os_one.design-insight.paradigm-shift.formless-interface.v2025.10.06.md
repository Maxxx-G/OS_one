# The Formless Interface
**Problem:** Big AI still surfaces "enter name/address" UX.
**Answer:** OS One maps intent → fields invisibly; user never sees forms.

## Design Tenets
- Unified personal ontology; secure local profile.
- Form adapters run in background; only disambiguation is asked.

## Guardrails
- Explain-before-act for sensitive data.
- Local-first with explicit remote escalation.
