# Hotkeys HUD Guard — v2025.10.07

## Purpose
Document the behavior, visual placement, and acceptance checks for the Voice HUD legend and inline hotkey hints feature.

## Overview
The Voice HUD Legend provides context-aware status descriptions next to the existing VoiceOverlay pill. A "?" button (and Alt+/ hotkey) toggles inline hotkey hints to help users discover keyboard shortcuts without leaving the screen.

## Components

### Voice Legend
- **Location**: Fixed top-right (24px from top and right edges)
- **Content**: Phase-specific text describing current voice state
  - `Muted` → "TTS disabled"
  - `Idle` → "Ready for input"
  - `Listening` → "Recording audio"
  - `Speaking` → "Playing response"
  - `Streaming` → "Receiving audio"
- **Button**: Small circular "?" button to toggle hints

### Hotkey Hints Panel
- **Trigger**: Click "?" button OR press Alt+/
- **Location**: Directly below legend (52px from top, 24px from right)
- **Content**: 4 keyboard shortcuts
  - `Alt+M` → Mic
  - `Alt+R` → Reasoning
  - `Alt+A` → Audit
  - `Alt+P` → Palette
- **Dismissal**: Click "?" again OR press Alt+/ again

## Hotkeys

### Alt+/ (Forward Slash)
- **Action**: Toggle hotkey hints panel
- **Scope**: Global (works anywhere in app)
- **Prevents**: Default browser behavior for Alt+/

## Visual Behavior

### No Layout Shift
- Both legend and hints use `position: fixed`
- No CLS (Cumulative Layout Shift) impact
- Hints overlay content without pushing elements

### Z-Index Layering
- Legend: `z-index: 999`
- Hints: `z-index: 998` (below legend, above most content)
- VoiceOverlay: Existing lower z-index

### Responsive Placement
- Fixed positioning ensures visibility on all screen sizes
- Right-aligned to avoid collision with left/center UI
