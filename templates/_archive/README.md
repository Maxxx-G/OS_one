# Templates Archive

**Purpose:** Historical versions of agent-critical templates that have been superseded.

**Rule:** Never delete templates. Archive them here for version history and rollback capability.

---

## Archival Format

Each archived template should be accompanied by a note in this file:

```
YYYY-MM-DD: {template-name}.v{old-date}.md
  → Superseded by: {template-name}.v{new-date}.md
  → Reason: {brief description of changes}
```

## Retrieval Protocol

If you need to reference an archived template:

1. **Check date:** Ensure you need the historical version (not latest)
2. **Note context:** Document why you're using archived version
3. **Validate:** Confirm template is compatible with current system
4. **Consider upgrade:** Evaluate if latest version is more appropriate
