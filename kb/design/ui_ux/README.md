# UI/UX Designs — Usage

## Structure

- `drafts/` — work in progress (screens, mocks, explorations)
- `final/` — approved snapshots for reference
- `source/` — editable source (fig/psd/sketch/svg), if any

## Naming (no spaces; underscores; fast ID)

Pattern:
`uiux_<project>_<view|flow>_<variant>_vYYYYMMDD[_HHMM][_author].<ext>`

Examples:

- `uiux_webui_selector_bar_v20250921_kharma.png`
- `uiux_chat_stream_output_v20250921_0030_gtanner.png`

## Notes

- Prefer PNG/JPG for drafts; SVG for vector UI parts.
- Keep huge originals in `source/`; export smaller PNG/JPG to `drafts/` or `final/`.
- When a draft is approved, move a copy to `final/` with same base name.
